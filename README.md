# PR Portfolio

Profile / Game / Portfolio 세 페이지로 구성한 빈 포트폴리오 템플릿입니다. 상단 페이지 메뉴, 왼쪽 세로 항목 선택, 중앙 이미지와 오른쪽 텍스트 영역을 제공합니다. 청록색 `#58A4B0`을 포인트로 사용합니다.

기존 인물 정보·사진·게임 레퍼런스·첨부 문서는 현재 소스와 배포 파일에서 제거했습니다. 기본 콘텐츠는 모두 공백이며, 이전 버전의 브라우저 저장 데이터는 사용하지 않습니다. Git의 과거 커밋은 보존됩니다.

## 한 화면에서 전체 수정

1. 웹사이트 오른쪽 아래 **전체 편집**을 누릅니다.
2. 사이트 제목과 메뉴 이름, 각 항목의 제목·설명·이미지·버튼을 같은 화면에서 입력합니다.
3. **일괄 입력할 페이지**를 선택하고 **이미지 여러 장 넣기**를 누르면 첫 항목부터 최대 8장까지 순서대로 들어갑니다. 이미지 선택 순서는 파일 선택기가 전달한 순서입니다. 업로드 이미지는 크기·용량을 줄이기 위해 WebP로 저장하며 GIF는 정지 이미지로 변환됩니다.
4. **글 여러 개 붙여넣기**를 누르면 글도 한 번에 넣을 수 있습니다. 첫 줄은 제목, 나머지는 설명이며 항목은 `---` 한 줄로 구분합니다.
5. **전체 저장하고 닫기**를 누릅니다.

수정본은 현재 브라우저에 저장됩니다. 공개 사이트에 반영하려면 **수정본 내보내기**로 받은 `portfolio-content.json` 파일을 이 채팅에 첨부하고 반영을 요청하세요. 또는 이름을 `content.json`으로 바꿔 저장소의 `site/content.json`을 교체하고 커밋하면 됩니다. 다른 기기에서는 내보낸 파일을 **수정본 불러오기**로 불러올 수 있습니다.

페이지마다 8개, 총 24개 항목입니다. 제목·설명·사진·버튼은 모두 비워 둘 수 있습니다. 비어 있는 화면의 Image / Text 표시는 안내용 자리 표시자입니다. 이미지·버튼 링크는 http/https 주소를 사용합니다. 각 항목의 제목은 왼쪽 항목 이름으로도 표시됩니다.

여러 이미지를 넣은 후 저장 공간이 부족하다는 메시지가 나오면 수정본을 내보내 보관하세요. 브라우저 저장소를 삭제하면 그 브라우저의 수정 내용이 사라집니다. 브라우저에 저장된 내용이 있다면 저장소 공통 `content.json`보다 우선하므로 공통 배포본 확인에는 시크릿 창을 사용할 수 있습니다.

## 파일

- `site/index.html`: 화면 골격과 전체 편집 창
- `site/canvas.css`: 화면·모바일·편집 디자인
- `site/canvas.js`: 빈 데이터 모델과 편집·일괄 입력·저장 기능
- `site/content.json`: 방문자 공통 기본 콘텐츠
- `.github/workflows/pages.yml`: main 푸시 시 자동 배포
